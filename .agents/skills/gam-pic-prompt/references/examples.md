# 示例

以下示例展示如何按素材用途选择视角和项目偏好。实际提示词应根据用户给出的主体与要求调整。

## 侧视角色首帧

用户希望生成一只适合作为动作视频首帧的鸭子法师：

```text
一只圆滚滚的黄色鸭子法师自然站立，身体侧向画面右方，扁扁的橙色鸭嘴和黑色圆眼清晰可见。它戴着深紫色尖顶法师帽，穿深蓝色长袍和淡紫色围巾，手持一根镶有蓝色水晶的木质法杖。角色全身完整地位于画面中央，姿态稳定，轮廓清楚，适合作为角色动作视频的首帧。背景是均匀纯亮绿色，角色身上没有亮绿色元素。水晶的微光限制在水晶和角色轮廓内部，不在外缘形成光晕。2D手绘动画风格，简洁赛璐璐上色。
```

## 俯视游戏角色

用户说明素材要放进俯视游戏场景：

```text
一名年轻的森林信使，背着小型皮革行囊，手握短杖，身体采用俯视游戏中清晰易读的三分之四视角，面部、双臂和鞋子都能辨认。她处于轻松待命姿势，完整呈现在画面中央，剪影与装备轮廓明确。使用2D手绘动画风格和自然的蓝色、棕色配色；背景为均匀纯亮绿色，角色配色与绿幕清楚区分，便于后续分离主体。
```

## 参考图：保留设计，改变姿势

用户提供一张原创狐狸斥候的参考图，希望角色跳上岩石：

```text
保留参考图中狐狸斥候的橙灰配色、长耳轮廓、深色皮革背心和轻便靴子，维持相同的2D手绘风格。将姿势改为她跃上低矮岩石、身体朝向画面右方并回头观察的瞬间；尾巴随动作向后扬起，表情专注。全身和尾巴完整可见，画面留出动作空间。背景使用均匀纯亮绿色，角色身上不出现与背景相同的亮绿色，也没有轮廓外溢的泛光。
```

## 用户明确需要其他背景色

用户要求将上述角色的背景改成蓝色时，先在提示词正文之外说明：

当前 gam 的去背流程针对绿色背景优化，后续会更新支持去除其他背景色；本次素材提示词仍使用绿色背景。

本次提示词继续明确使用均匀纯亮绿色背景。若用户要求保留的角色本身含亮绿色，同时说明同色区域可能被误删，保留角色配色，不自行换底或改色。

## 从现有知名角色请求转为原创设计

当用户要求直接复刻知名角色时，先把创作方向抽象成宽泛特征，再写原创描述。例如保留“奇幻冒险者、沉稳、冷色调、轻甲”这样的方向，同时设计不同的轮廓、服装结构、配件和名称；不要复现能识别原角色的标志性元素。真人角色改写为原创人物设定，不描述其可识别肖像。
