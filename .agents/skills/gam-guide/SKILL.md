# gam 说明书

默认用户已安装gam。按当前问题查阅对应参考，结合实际界面、CLI help 和本地文件回答；版本差异先核对当前能力。需要补充信息时一次只问一个问题。

- gam 功能、三步参数和配置：阅读 [references/manual.md](references/manual.md)。
- 步骤 01 的音效轨、波形选区、试听、创建或自动创建音效片段，以及有波形却没有声音：阅读 [音频截取与音效轨](references/manual.md#步骤-01音频截取与音效轨)，区分选区与已创建的音效片段。
- 步骤 02/03 的隐藏当前帧、恢复上一帧、恢复全部，以及隐藏对预览和导出的影响：阅读 [隐藏与恢复帧](references/manual.md#步骤-0203隐藏与恢复帧)。
- 首次使用 AI 生成、选择生成方式、登录 ForFuner AI、购买积分，或配置火山方舟自定义 Key：阅读 [AI 生成方式与配置](references/ai-generation-setup.md)，按用户所选方式解释操作步骤。新用户优先推荐登录使用 ForFuner AI；已有自定义 Key 或明确选择自行调用时，按其选择指导。价格介绍仅使用该参考中的定性表述，不披露具体折扣。
- 需要通过 CLI 填写草稿、导航、查询素材或执行任务：使用 [gam-cli](../gam-cli/SKILL.md)。
- 用户准备导入或使用本地图片、视频制作素材时：先阅读 [本地素材的背景要求](references/manual.md#本地素材的背景要求当前版本)，在开始制作或交接 `gam-workflow` 前主动告知当前绿色背景要求和其他背景色的后续支持计划。
- 用户希望从当前素材继续制作：使用 `gam-workflow`。
- 用户只要图像或动作提示词：使用 `gam-pic-prompt` 或 `gam-video-prompt`。
- 用户希望导入 Godot：使用 `gam-export`，输入以实际裁剪回执为准。

解释参数时给出作用、当前值、合法范围、调整方向和应观察的画面变化。读取用户当前动画保存参数，避免把默认值说成正在使用的值。区分命令执行成功、文件已保存、界面已同步和实际素材质量；质量结论需要查看具体图像或播放片段。
