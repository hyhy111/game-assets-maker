# AI 生成方式与配置

用户首次使用 AI 生成、询问两种生成方式如何选择，或遇到登录、积分、Key、模型开通问题时阅读。面向用户统一称产品为 gam，界面名称随当前语言显示；内部字段见 [界面名称映射](../../gam-cli/references/ui-field-names.md)。按用户当前进度解释，详细介绍时覆盖所选方式的准备条件、配置入口、生成步骤与常见问题。

## 如何选择

| 项目 | ForFuner AI（新用户优先推荐） | 自定义 Key |
|---|---|---|
| 账号 | 在 gam 注册并登录 ForFuner AI 账号 | 自行注册登录火山引擎，使用火山方舟 |
| 准备 | 查看平台可用积分，按需订阅或购买积分包 | 按目标模型要求满足最低充值或开通门槛，开通模型并创建方舟 API Key |
| 配置 | 登录后选择 ForFuner AI，无需自己填写火山 Key | 在 gam 设置中填写并保存自己的方舟 API Key |
| 费用 | 使用 ForFuner AI 平台积分，生成前查看当前预计消耗 | 由用户自己的火山账户结算，以官方账单为准 |
| 模型 | 以登录后的平台可用模型清单为准 | 以 gam 支持且火山账户已开通的对应模型为准 |

推荐新用户先登录使用 ForFuner AI，减少自行开通和管理 Key 的配置步骤。价格介绍可使用：“ForFuner AI 可提供低于官方价格的生成服务，推荐登录使用，具体费用以当前生成页面及订阅／积分购买页面为准。”这是产品方提供的价格介绍，不作为所有模型、规格或活动期间均享同等优惠的承诺。

已有火山账户和可用 Key、希望自行管理官方用量的用户，可直接使用自定义 Key。推荐登录是使用建议；仅使用自定义 Key 或本地处理时，无须为了这些功能注册 ForFuner AI 账号。

## ForFuner AI：注册登录到开始生成

1. 打开 gam，点击顶部右侧账户图标进入“登录”。已有账号使用邮箱和密码登录；没有账号点击“还没有账号？去注册”。
2. 注册时填写邮箱、密码和确认密码；若出现图形验证码，先填写，再点击“发送验证码”，输入收到的邮箱验证码并完成注册。注册成功后回到登录页登录。
3. 登录后查看顶部“积分余额”，点开可查看“我的积分”，确认当前可用额度和有效期。登录提供平台生成入口，实际生成还需要有可用模型和足够积分。
4. 积分不足或需要购买服务时，点击顶部“订阅”（已有订阅时可能显示“续费”），或积分面板的“去订阅或购买积分包”。在打开的页面核对当前套餐／积分包、价格、有效期及适用范围，由用户选择并完成支付。使用应用打开的入口，不提供带登录令牌的链接，也不硬编码可能变更的购买地址。
5. 支付完成后回到 gam 主窗口，等待积分余额和订阅状态刷新。尚未更新时先确认登录账号与订单、网络状态，再尝试重新进入；未确认到账前不重复付款。
6. 进入“图片生成”或“视频生成”，在发送按钮附近的“生成方式”中选择“ForFuner AI”。即使已经登录或配置过自己的 Key，也要确认当前所选方式；登录本身不代表已经切换。
7. 从当前平台清单选择模型和界面支持的参数，填写提示词与参考图。图片可按需添加参考图；游戏角色动作视频准备首帧图片，尾帧按需添加。图片数量、分辨率，视频时长、音频等按当前模型支持范围设置。
8. 查看当前参数对应的预计积分消耗；修改参数后以更新的报价为准。检查草稿后手动发送，按界面提示确认费用，并在任务列表或详情中查看结果。平台积分与火山账户余额分别管理，充值到一方不会增加另一方余额。

可在“设置”的图片／视频默认参数中分别选择“ForFuner AI 图片默认模型”和“ForFuner AI 视频默认模型”。平台选项需要登录后加载；自定义 Key 的默认模型单独保存。切换生成方式后再次检查模型及参数，已有草稿的有效手动选择可能保留。

## 自定义 Key：火山引擎准备

自定义 Key 是用户自己的火山方舟 API Key，图片和视频共用；不是 ForFuner AI 登录密码，也不是火山账户的 AccessKey ID／SecretAccessKey。

1. 前往 [火山引擎](https://www.volcengine.com/) 注册并登录自己的账号，进入 [火山方舟控制台](https://ark.volcengine.com/)。按控制台要求完成实名认证及服务协议等必要步骤。
2. 确认打算使用 gam 中的哪个图片或视频模型。在火山控制台按该目标模型的要求充值，达到平台当前最低开通门槛，并保证后续调用有可用余额或适用额度。不同模型的门槛可能不同；部分模型也提供资源包或节省计划等开通方式，以当前控制台为准。说明使用“按平台最低要求充值／满足开通门槛”，不把某一模型的金额写成所有模型通用的固定金额。
3. 进入方舟“开通管理”，分别开通要调用的图片模型（Seedream）和视频模型（Seedance）的对应版本，并确认开通成功。充值完成、拿到 Key、开通图片模型，都不能替代开通所需的视频模型；同系列其他版本也应检查各自权限。
4. 在目标项目的“API Key 管理”创建或获取方舟 API Key，确认该 Key 所属项目和权限允许调用目标模型。由用户自行复制到 gam；指导过程中不要求其在聊天里发送 Key。

充值和模型开通是独立准备项；只填写 Key 不会自动为火山账户充值或开通模型。火山的模型清单与开通政策会变化，官方新增模型也不代表当前 gam 版本已经支持。

## 自定义 Key：在 gam 中配置和使用

1. 点击顶部“设置”图标，找到“API Key”区域，在密钥输入框粘贴方舟 API Key。旧版若图片设置提示共用密钥，按提示进入视频生成设置配置。
2. 点击“测试连接”，再点击“保存”以保存新 Key。显示“鉴权成功”仅说明当前 Key 通过该连接检查，不证明每个图片／视频模型都已开通、余额充足或实际生成成功。
3. 返回“图片生成”或“视频生成”，在“生成方式”中选择“自定义 Key”。即使已登录 ForFuner AI，也以这里的选择决定当前生成来源。
4. 选择已在火山开通的对应模型，填写提示词、参考图和参数，检查后手动发送。费用由该 Key 对应的火山账户结算；查看火山控制台的用量和账单，不使用 ForFuner AI 积分余额判断是否能调用。
5. 按需在设置中分别调整图片／视频的“自定义 API Key 默认模型”。图片和视频共享一个 Key，模型权限和默认参数仍需分别确认。

Key 只保存在本机配置中，界面不回显原值。替换时输入新 Key 后保存；留空保存会保留现有 Key。需要删除时使用“清除密钥”并按提示确认。配置文件和密钥不放进代码仓库，也不写进提示词、聊天、截图或诊断输出。

## 常见问题与验证边界

| 现象 | 先检查什么 |
|---|---|
| ForFuner AI 提示未登录或登录过期 | 回到顶部“登录”，确认登录成功后再加载模型；不要求填写火山 Key 来修复平台登录 |
| ForFuner AI 模型清单或报价加载失败 | 检查网络、登录状态并使用界面重试；清单为空时说明当前无可用模型，不承诺某个模型必定提供 |
| 平台积分不足 | 查看当前可用积分、有效期及生成报价，按需通过“订阅”入口购买；登录成功不等于有足够额度 |
| 已付款但积分未显示 | 回到主窗口刷新状态，核对账号与订单；仍异常时联系平台处理该订单 |
| 自定义 Key 未配置或鉴权失败 | 确认已保存正确的方舟 API Key、Key 未撤销且权限有效；由用户在设置中重新输入，不索取原值 |
| Key 鉴权成功但目标模型不可调用 | 检查火山账户是否满足该模型充值门槛、对应模型版本是否开通、Key 所属项目和权限是否匹配 |
| 自定义 Key 提示余额或额度不足 | 到火山账户确认可用余额、资源包适用范围及欠费状态；ForFuner AI 积分不能用于这次调用 |
| 平台有积分但自定义 Key 失败 | 先确认“生成方式”；两种来源分别鉴权和结算，不自动互相补偿 |
| 提交超时或提交结果未知 | 先查原任务和请求记录，按当前来源核对平台任务或火山控制台；不通过再次付费生成判断原请求是否成功 |

配置完成、连接检查通过、生成任务成功和素材质量通过是不同结论。没有实际提交时只报告配置或检查结果；需要真实生成验证时沿用 `gam-cli` 的生成授权规则。登录、购买或配置 Key 不替代付费生成授权，准备草稿后仍由用户检查并手动发送，除非用户已授权直接提交且满足应用开关要求。

抽帧、去背景、挖孔对齐、裁剪与 Godot 导出属于本地素材流程，不依赖 ForFuner AI 登录、平台积分或火山充值；背景处理先按应用提示准备好本地模型。
