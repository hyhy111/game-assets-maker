# 起点与授权走查

| 用户起点 | 先收集的证据 | 下一步 |
|---|---|---|
| “做一只史莱姆” | 游戏视角与素材用途；缺视角时只问视角 | 写图像提示词、准备草稿，由用户发送 |
| “让这张图吼叫” | 实际角色图、朝向与动作终态 | 写首帧驱动动作提示词，填写视频草稿 |
| “这个视频抠图后有绿色孔洞” | 项目 ID、步骤 2 透明帧和步骤 3 当前参数 | 检查角色绿色与孔洞区别，调整挖空参数后本地执行 |

| 情境 | 行为 |
|---|---|
| 默认关闭、用户想自动创建 | 准备草稿，说明设置入口；等待软件开启确认 |
| 开关开启、当前对话第一次 | 说明内容、数量及费用可能性，等待用户明确确认 |
| 用户尚未回答或拒绝 | 保持草稿，不提交 |
| 当前对话已经确认 | 查最新开关后直接提交后续任务 |
| 新对话或无法证明确认属于当前对话 | 重新确认 |
| 用户撤销或开关关闭 | 停止新提交；仍可查询旧任务和本地处理 |
| 提交超时或 SUBMISSION_UNKNOWN | 查原 request_id、任务记录与目录，保持不重试 |
| 已保存任务但 ui_sync=pending | 报告任务 ID 和待同步状态，先恢复查询，不新建任务 |

没有看到生成图片、视频或过程帧时，说明缺少质量证据，先读取可用缓存媒体；任务 completed 只证明处理完成。

只有原始视频、尚无项目时，确认角色与动作名称后执行 `gam-agent project create --video /绝对路径/视频.mp4 --role 角色 --action 动作`，记录返回的项目 ID。先读取步骤 1 参数并检查源帧，再执行提取；后续按步骤 2／3 顺序处理，无须登录或开启 CLI 生成。
