# 动作细化参考

按角色实际身体结构和动作选择词语，把它们组织成连贯描述。用于细化动作，不作为必须堆满的关键词清单。

## 动作的因果链

准备姿势 → 支撑与重心变化 → 主动肢体发力 → 武器或道具运动 → 衣物、尾巴等滞后运动 → 收招或终态。

例如挥锤：双脚站稳、重心下沉 → 腰部与肩背转动 → 手臂带动锤柄 → 锤头完成挥击 → 衣摆随惯性摆动 → 稳住身体并收回武器。

## 肢体与接地

- 站立：双脚接地，重心稳定，姿态与 @图片1 一致。
- 行走：双脚交替支撑，落脚、承重、抬脚顺序清晰，身体适度起伏。
- 奔跑：步频加快，身体适度前倾，短暂腾空与落脚交替。
- 跳跃：屈膝蓄力、蹬地、腾空、最高点过渡、下落、落地缓冲。
- 翻滚：降低重心、收拢身体、旋转、重新接地、恢复站姿。武器随持握运动，幅度以取景范围为限。
- 受击：冲击方向明确，身体反应、补步找回平衡、稳定恢复。
- 倒地：失去支撑、下沉倾倒、接地、运动逐渐停止。

鸟类可用翅膀和脚爪、四足角色可用前后肢，尾巴跟随重心和惯性；仅使用 @图片1 中已有的身体结构。

## 武器运动

- 横斩：身体带动手臂，武器沿清楚的横向弧线挥出。
- 斜劈：准备时抬起武器，随后沿斜向轨迹发力，最后减速收回。
- 直刺：重心前移，持握肢体沿朝向推出，随后回收。
- 格挡：抬起武器或盾牌稳住，躯干与支撑脚承受力度，再恢复姿态。
- 施法：收杖蓄势、前伸指向、停顿、收回，通过纯身体动作表现。

保持 @图片1 的持握关系，武器运动有路径和惯性，不自动脱手、变形或替换。

## 视角与空间

- 画面右上：角色朝右上方，斜俯视背侧朝向。
- 画面右下：角色朝右下方，斜俯视正侧朝向。
- 画面上方：角色背对观看者。
- 画面下方：角色正面朝向观看者。
- 侧视：沿 @图片1 的横向朝向。

这些对应关系适用于常见斜俯视角色素材，具体投影以 @图片1 为准。角色朝向、画面位移和持武器的手是不同信息，分别描述；原地行走中的“朝右上方迈步”不意味着身体根部必须移到画面右上角。

## 次级运动与可读性

衣物和尾巴根据主动作延迟摆动、回弹、稳定。起跳时随加速度滞后，下落与落地时随惯性调整；不要机械规定每次起跳披风都向上飘。动作的力度来自重心、支撑和肢体发力，取景和轮廓应让关键部位清晰可辨。
