# Spec Delta

## Purpose

为旧项目映射和统一设置页提供一致的非原生下拉控件，使选项选择、键盘操作、尺寸和视觉反馈符合项目现有交互模式。

## ADDED Requirements

### Requirement: 迁移映射使用一致的目标角色选择控件
系统 SHALL 使用项目标准的非原生选择控件呈现旧项目映射中的目标角色选项，而不得使用浏览器原生下拉框。该控件 MUST 显示未选择提示，并与同一行的目标动画输入框具有一致的控制高度。

#### Scenario: 选择目标角色
- **WHEN** 用户打开某个旧项目的目标角色选择控件并选择角色
- **THEN** 映射草稿更新为所选角色
- **AND** 目标动画字段与批量迁移资格判定保持原有行为

#### Scenario: 尚未选择目标角色
- **WHEN** 某个旧项目尚未设置目标角色
- **THEN** 控件显示选择提示
- **AND** 批量迁移操作保持不可用，直至所有映射完整

### Requirement: 统一设置页的下拉控件保持一致
系统 SHALL 将统一设置页内的 Seedance 默认模型、分辨率、比例、时长、Seedream 默认模型、分辨率、比例、数量及缓存保留时长全部呈现为项目标准的非原生选择控件。每个控件 MUST 保留原有选项、测试标识、保存绑定与依赖修正规则，并与同一设置页的输入控件保持一致的视觉高度。

#### Scenario: 修改 Seedance 默认模型
- **WHEN** 用户使用新选择控件修改 Seedance 默认模型
- **THEN** 系统执行既有的默认值修正逻辑
- **AND** 保存后仍提交合法的模型、分辨率、比例与时长配置

#### Scenario: 修改数值型默认值
- **WHEN** 用户使用新选择控件修改默认时长、默认数量或缓存保留时长
- **THEN** 对应设置保持数值类型
- **AND** 保存与缓存清理可用性保持原有行为

#### Scenario: 键盘访问选择控件
- **WHEN** 用户以键盘聚焦任一迁移或设置页选择控件
- **THEN** 用户可以打开选项、移动焦点、确认选择并关闭选项列表
- **AND** 焦点状态清晰可见
