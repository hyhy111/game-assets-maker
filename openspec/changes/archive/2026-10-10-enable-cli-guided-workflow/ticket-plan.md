# Matt ticket 拆分稿

状态：用户已确认拆分与本地 tracker，11 个正式 ticket 已发布。

## 依据与后续流程

需求唯一依据为 OpenSpec 变更 `enable-cli-guided-workflow` 的 proposal、design 和四项 delta specs。tickets 是执行切片；遇到需求冲突先修订 OpenSpec，再同步 tickets，不另外撰写 to-spec。

建议使用本地 tracker：`.scratch/enable-cli-guided-workflow/issues/`，确认后按下列顺序发布一票一文件。当前仓库未配置 Matt tracker；本次确认同时选择本地文件模式，不初始化远程 tracker、标签或其他项目设置。

每票通过 Matt `implement` 执行，在行为边界使用 `tdd`，完成后用 `code-review` 检查标准与规格，保留验证记录。仅修改票内范围，不处理并行变更。每个 ticket 自包含，后续上下文从 ticket 与其 OpenSpec 来源恢复。原 OpenSpec tasks 保持进度，票内勾选不能提前把未完成的桌面验收标为完成。

遵守项目 Git 规则：本次不自动 commit 或 push；Matt implement 中提交步骤仅在用户另行授权后执行。代码与验收完成后再同步 delta specs、严格校验并归档 OpenSpec，归档授权来自本次用户指示。
