## Purpose

为通过 Agent CLI 直接提交 AI 图片和视频生成建立明确的用户授权边界：应用设置默认禁止，用户在界面确认后才允许，Agent 在每个新对话首次提交前再取得确认，避免草稿操作意外成为付费生成。

## ADDED Requirements

### Requirement: CLI 生成授权默认关闭且只能在设置中确认开启
设置 SHALL 提供“允许 CLI 提交 AI 生成任务”开关，缺失或非法配置 MUST 视为关闭。用户尝试开启时 MUST 弹窗说明 CLI 可直接提交图片／视频生成、可能产生费用，以及当前对话首次确认规则；用户确认后才保存开启，取消或保存失败保持原有效值。CLI MUST 可读取有效状态，但 MUST NOT 通过自身命令开启该权限。普通启动软件时 MUST NOT 因此重复弹窗。

#### Scenario: 老配置没有该开关
- **WHEN** 应用读取不含 CLI 生成授权字段的配置
- **THEN** 权限为关闭，设置显示关闭

#### Scenario: 用户确认开启
- **WHEN** 用户在设置中尝试开启并确认功能说明
- **THEN** 系统保存开启状态，界面与 CLI 查询一致

#### Scenario: 用户取消或保存失败
- **WHEN** 用户取消弹窗或持久化失败
- **THEN** 不开启权限；失败时说明原因
- **AND** 不提交其他未保存设置

#### Scenario: 重启软件
- **WHEN** 软件再次启动
- **THEN** 读取保存状态，正常启动不弹出 CLI 授权说明

### Requirement: 程序在每次 CLI 远端提交前校验有效开关
每次由 CLI 发起图片或视频远端生成前，系统 MUST 校验最新有效授权，不得只在 CLI 启动时缓存状态。关闭时 MUST 在远端提交前拒绝并返回稳定错误，已有 `seedance create` 入口同样 MUST 受控；关闭不得限制桌面用户手动发送、只读查询、草稿准备、本地处理、裁剪和 Godot 导出。CLI 有授权时 MUST 复用应用当前支持的生成来源与校验，不能静默换用另一来源或绕过已有计费确认语义。

#### Scenario: 关闭时调用现有创建命令
- **WHEN** CLI 生成权限关闭，调用现有视频创建或新增图片创建命令
- **THEN** 返回禁止 CLI 生成错误，无远端生成请求

#### Scenario: 对话已授权后关闭设置
- **WHEN** 用户已允许当前对话提交，随后关闭软件设置开关
- **THEN** 后续 CLI 提交仍被程序拒绝
- **AND** 对话确认不能覆盖设置开关

#### Scenario: 关闭时准备草稿或本地处理
- **WHEN** CLI 更新参考图、恢复再次生成草稿、读取缓存或执行三步处理／裁剪
- **THEN** 这些操作不受 CLI 生成开关限制
- **AND** 桌面用户仍可手动点击发送生成任务

### Requirement: Agent 每个新对话首次提交前取得确认
gam 主流程技能 MUST 在当前对话首次通过 CLI 提交 AI 生成前说明拟生成内容及可能费用，并取得用户明确确认；确认后本对话后续请求可直接提交，不逐任务重复询问。新对话 MUST 重新确认，不能从软件开启状态或旧对话记录推断已确认；明确撤回后 MUST 停止提交。该对话规则由技能执行，程序设置校验仍独立适用，命令成功不能证明 Agent 已询问用户。

#### Scenario: 已开启设置但新对话尚未确认
- **WHEN** 新对话首次准备提交生成任务
- **THEN** Agent 先请求明确确认，未确认时只可准备草稿

#### Scenario: 同一对话继续生成
- **WHEN** 用户已明确确认当前对话，设置仍开启，后续继续要求生成
- **THEN** Agent 可直接提交，不再次询问逐任务授权

#### Scenario: 首次确认前被拒绝
- **WHEN** 用户拒绝或尚未回答首次授权问题
- **THEN** Agent 不提交生成任务，不把超时或沉默视为确认

### Requirement: 生成状态与再次生成和下载语义可区分
CLI SHALL 区分草稿恢复、新生成提交、任务状态查询和已有结果下载。新生成成功 MUST 返回可追踪任务标识；未知提交状态 MUST 明确报告并禁止 Agent 自动再发一次。关闭开关 SHALL 只阻止之后的新提交，不撤销已接收的任务或阻止其查询／下载。

#### Scenario: 再次生成只回填
- **WHEN** 用户要求恢复已有任务的再次生成草稿
- **THEN** CLI 回填提示词、图片和参数，不发送新的远端请求

#### Scenario: 请求结果不明
- **WHEN** 提交后无法确定生成服务是否接收
- **THEN** 返回结果不明的可恢复状态
- **AND** Agent 先查询与核对，不自动重复提交

#### Scenario: 关闭时已有任务仍运行
- **WHEN** 用户在已提交任务运行中关闭授权
- **THEN** 新提交被阻止，已有任务查询与下载继续可用
