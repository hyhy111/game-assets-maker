## Purpose

为 Game Assets Maker 的 Agent CLI 提供与桌面应用共享的生成草稿、处理参数、任务执行和页面导航能力，使用户能看到并复查 Agent 的修改，避免参数持久化、界面状态和实际执行结果彼此脱节。

## ADDED Requirements

### Requirement: CLI 按字段更新生成草稿并保留其他内容
CLI SHALL 支持读取与更新图片和视频生成草稿，包括提示词、图片生成的唯一参考图、视频的首帧与可选尾帧，以及现有界面支持的生成参数。更新 MUST 只修改明确指定的字段；未指定字段保持不变。系统 MUST 在修改前校验字段、值与图片可用性，失败时保持原草稿，并返回明确错误；成功时界面显示实际选用图片与参数。草稿更新 MUST NOT 自动提交生成任务。

#### Scenario: 只替换视频首帧
- **WHEN** 视频草稿已有提示词、首帧、尾帧和参数，CLI 只指定新的首帧图片
- **THEN** 首帧及缩略图更新为指定图片
- **AND** 提示词、尾帧、参数不变，不产生生成请求

#### Scenario: 同时填写提示词和参考图
- **WHEN** CLI 更新图片草稿的提示词和唯一参考图
- **THEN** 两个字段一起通过校验后显示在图片输入区域
- **AND** 参考图仍为一张，其他字段保留

#### Scenario: 一个字段校验失败
- **WHEN** 同一次更新中包含不可读取的图片或不支持的字段／参数
- **THEN** 系统拒绝整次更新并指出原因
- **AND** 不保留半更新的提示词或图片状态

### Requirement: 再次生成恢复草稿而非提交任务
CLI SHALL 支持基于已有图片批次或视频任务恢复再次生成草稿，包括已有提示词、参考图／首尾帧及参数；此显式恢复操作 MUST 与局部字段更新区分，且 MUST NOT 创建新生成任务。

#### Scenario: 恢复历史视频草稿
- **WHEN** CLI 选择一个有可用本地输入素材的历史视频任务并请求再次生成草稿
- **THEN** 系统回填该任务的提示词、首／尾帧和参数
- **AND** 用户仍可检查、修改或手动发送，无远端生成请求

#### Scenario: 历史素材已清理
- **WHEN** 历史草稿所需本地图片不存在
- **THEN** 系统报告缺失输入并保留当前草稿

### Requirement: 三步处理参数具有明确的 CLI 支持范围
CLI SHALL 支持步骤 1 的帧提取间隔、起始帧、结束帧；步骤 2 的 Alpha Matting、腐蚀大小、前景阈值、背景阈值；步骤 3 的挖空处理开关、检测强度、羽化半径、最小挖空、帧对齐开关、水平居中开关和底部对齐开关。CLI SHALL 可读取、按字段更新并保存这些参数。参数语义、有效范围和处理依赖 MUST 与现有应用一致，由后端校验；未指定参数及其他项目、步骤的参数 MUST 保留，不使用默认值覆盖已保存值。

#### Scenario: 调节指定动作的步骤 2 参数
- **WHEN** CLI 对某角色的指定动画修改腐蚀大小和前景阈值
- **THEN** 系统保存该项目步骤 2 的合法修改
- **AND** Alpha Matting、背景阈值、其他步骤及其他动画的参数不变

#### Scenario: 非法帧范围
- **WHEN** CLI 指定非法帧间隔、起始帧或结束帧
- **THEN** 系统返回字段错误，不保存或开始提取
- **AND** 结束帧的现有全部帧约定继续有效

### Requirement: 参数保存与界面同步具有可验证回执
CLI 修改处理参数后 MUST 保存到对应项目，并在应用运行时同步显示；命令 MUST 分别报告持久化和界面应用结果，不把事件已发送视为界面已应用。多个项目与并发命令 MUST 使用明确的目标标识，不能更新错误项目。应用未运行时，参数保存与已有本地操作 SHALL 可用，但 MUST 明确报告界面未同步；生成草稿与导航操作 MUST 返回应用未运行错误，不伪造成功。

#### Scenario: 界面显示已保存参数
- **WHEN** 应用正在运行，CLI 对指定项目更新参数
- **THEN** 界面显示后端实际保存值
- **AND** CLI 在取得对应界面应用结果后报告已同步，重开项目时读取相同值

#### Scenario: 保存成功但界面应用失败
- **WHEN** 参数已经保存，但界面未就绪或同步超时
- **THEN** CLI 分别报告已保存和界面未同步，并提供刷新／重新打开建议
- **AND** 不宣称整体已经同步，不自动重复处理或提交生成

#### Scenario: 应用未运行
- **WHEN** CLI 保存合法处理参数但桌面应用未运行
- **THEN** 参数持久化成功，返回界面未运行状态
- **AND** 下次应用打开该项目时显示保存值

### Requirement: 三步处理复用同一项目的实际参数
CLI SHALL 支持执行步骤 1 帧提取、步骤 2 背景处理和步骤 3 挖空／对齐处理，使用该项目最新保存参数与本次明确覆盖项；覆盖项 MUST 按同样规则保存和同步。CLI MUST 返回任务标识、实际参数、最终状态和输出目录，失败或未完成时不得宣称成功。本地处理 MUST NOT 依赖登录或 CLI 生成授权开关。

#### Scenario: 执行已调节的步骤 3
- **WHEN** 用户先通过 CLI 保存挖空／对齐参数，再执行步骤 3
- **THEN** 处理使用保存值并返回实际参数和输出目录
- **AND** 应用运行时刷新该动作的处理状态与输出预览

#### Scenario: 前置输出缺失
- **WHEN** 执行步骤 2／3 所需的前置输出不可用
- **THEN** CLI 返回缺少输入的错误和必要的前置操作，不标记步骤已完成

### Requirement: CLI 可导航现有功能界面
CLI SHALL 支持跳转项目列表、创建项目、指定项目的三个处理步骤、批量裁剪、图片／视频创建、已有图片／视频详情和设置入口。导航 MUST 使用明确目标并保持现有页面前置条件；不得清空无关草稿或绕过页面校验。不存在的项目、任务或不支持目标 MUST 返回明确错误。

#### Scenario: 跳转指定动作的处理步骤
- **WHEN** CLI 指定有效项目和步骤 2
- **THEN** 应用加载该项目并显示对应步骤和保存参数
- **AND** 回执标识实际打开的项目与页面

#### Scenario: 跳转已有生成详情
- **WHEN** CLI 指定有效图片批次或视频任务
- **THEN** 应用显示对应详情而非另一条历史记录
