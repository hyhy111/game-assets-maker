# background-removal-model-readiness Specification

## Purpose

将 U2Net 的首次下载提示限定在真正需要背景移除的步骤，使帧提取保持独立并让模型准备状态在正确的操作上下文中呈现。

## Requirements

### Requirement: 帧提取不显示背景移除模型下载卡
系统 MUST NOT 在步骤 1（帧提取）显示 U2Net 模型状态卡、下载来源选择器、下载按钮或重试按钮，无论模型处于缺失、下载中、初始化中、失败或就绪状态。步骤 1 MUST NOT 因进入该步骤而启动 U2Net 的准备或下载。

#### Scenario: U2Net 缺失时打开步骤 1
- **WHEN** U2Net 模型在本机不存在且用户打开步骤 1
- **THEN** 帧提取界面不显示首次下载卡或任何模型下载控件
- **AND** 系统不发起 U2Net 下载

#### Scenario: U2Net 已就绪时打开步骤 1
- **WHEN** U2Net 模型已经可用且用户打开步骤 1
- **THEN** 帧提取界面不显示模型状态卡
- **AND** 帧提取操作保持可用

### Requirement: 背景移除步骤负责 U2Net 首次下载提示
系统 SHALL 在步骤 2（背景移除）检查当前背景移除模型的可用状态。仅当 U2Net 缺失、正在准备或准备失败时，步骤 2 MUST 显示模型状态卡；模型已就绪时不得显示首次下载卡。下载必须继续由用户选择来源并显式触发，失败后可重试。当下载或重试入口可用时，下载来源 MUST 使用项目标准的非原生选择控件，默认选中 ModelScope，支持 ModelScope 与 GitHub，并将用户当前选择的来源传递给下载或重试操作。

#### Scenario: U2Net 缺失时打开步骤 2
- **WHEN** U2Net 模型在本机不存在且用户打开步骤 2
- **THEN** 系统显示首次下载卡、下载来源和下载操作
- **AND** 背景移除操作保持不可用，直至模型就绪

#### Scenario: U2Net 下载完成
- **WHEN** 用户在步骤 2 触发下载且模型完成初始化
- **THEN** 系统隐藏首次下载卡
- **AND** 在步骤 1 已完成的前提下，背景移除操作变为可用

#### Scenario: U2Net 准备失败
- **WHEN** 步骤 2 的下载或初始化失败
- **THEN** 系统在步骤 2 显示失败状态与重试操作
- **AND** 不在步骤 1 显示该失败状态

#### Scenario: 选择下载来源后重试
- **WHEN** U2Net 缺失或准备失败，用户在步骤 2 将下载来源切换为 GitHub 并触发下载或重试
- **THEN** 系统使用 GitHub 作为该次下载或重试的来源
- **AND** 选择器可通过键盘聚焦、展开、选择和确认
