# cli-local-artifacts

## Purpose

使 Agent 能以角色、动画和生成任务为线索发现本地过程素材与 AI 缓存，读取可用于结果检查和风格复用的信息，并将多选裁剪的真实结果目录交给 Godot 导出流程，同时遵循用户配置的存储位置。

## Requirements

### Requirement: 角色与动画列表支持精确多选
CLI SHALL 提供角色列表及指定角色下的动画列表，返回稳定项目标识、显示名称、处理状态和可用输出信息。裁剪选择 MUST 使用项目标识，可跨角色多选；未选择的动画不得被处理。

#### Scenario: 同名动画属于不同角色
- **WHEN** 两个角色均包含名为“攻击”的动画
- **THEN** CLI 返回可区分的项目标识
- **AND** 用户选择其中一个时不处理另一角色的动画

#### Scenario: 用户多选动画
- **WHEN** CLI 选择三个有效项目执行裁剪
- **THEN** 系统只对这三个项目执行操作
- **AND** 返回逐项目结果供 Agent 检查

### Requirement: 多选裁剪支持两种模式和导出交接
CLI SHALL 支持统一包围盒裁剪与逐帧紧致裁剪，沿用现有源步骤选择和隐藏帧处理规则。结果 MUST 分别包含实际成功帧数、失败信息、最终帧目录及可用的偏移和音频清单路径；整个输出批次的根目录 SHALL 可发现。逐帧裁剪 MUST 保留偏移数据；两种模式均 SHALL 提供实际存在的目录用于 `gam-export`，不重新猜测或拼接输出路径。

#### Scenario: 统一包围盒裁剪成功
- **WHEN** CLI 多选项目并采用统一包围盒模式
- **THEN** 输出统一尺寸的 PNG 序列与逐项目最终目录
- **AND** 有音频清单时返回其路径，无偏移文件时明确表示不存在

#### Scenario: 逐帧紧致裁剪成功
- **WHEN** CLI 使用逐帧紧致模式
- **THEN** 输出 PNG 序列和逐帧偏移文件
- **AND** 返回结果目录，可直接作为 `gam-export` 输入

#### Scenario: 裁剪部分失败
- **WHEN** 某些图片处理或音效导出失败而其他输出成功
- **THEN** CLI 明确返回部分成功及逐项失败／跳过情况
- **AND** 不把缺失文件标为可用，不把部分成功当作完整交付

### Requirement: 可发现过程文件和 AI 生成缓存
CLI SHALL 提供当前配置项目根及共享 AI 缓存根中的文件发现，覆盖项目源素材、本地各步骤的过程与输出文件、裁剪结果、音频与其时间线、参数，以及已有图片／视频任务的输入、生成输出和可读缓存信息。查询 SHALL 支持按角色、项目、步骤或生成任务筛选与分页，返回文件标识、类型、绝对本地路径和存在／可用状态；不因未启用 CLI 生成而禁止读取。

#### Scenario: 查看动画各步骤素材
- **WHEN** Agent 查询指定动作的过程文件
- **THEN** 返回实际存在的步骤素材、输出和参数信息
- **AND** Agent 可区分步骤、帧序与尚未产生的输出

#### Scenario: 使用自定义缓存根
- **WHEN** 用户配置了自定义项目或共享 AI 缓存目录
- **THEN** CLI 从解析后的有效目录读取
- **AND** 不继续使用旧根、仓库示例目录或固定端口媒体 URL 作为本地路径

### Requirement: 文件读取保留可用溯源并控制内容边界
CLI SHALL 提供过程配置、任务缓存与历史提示词的受控读取，返回提示词、生成参数、来源任务／步骤和可用素材信息；图片、视频和音频 SHALL 以可供 Agent 工具读取的本地文件信息返回，不将整个二进制文件混入默认 JSON 输出。CLI MUST 排除凭证与密钥信息并隐藏缓存响应中的敏感临时访问数据；不存在、已清理、不支持或超出应用数据范围的目标 MUST 明确报错。列表成功 MUST NOT 表示画面、音频或动作质量已经通过检查。

#### Scenario: 获取历史提示词用于风格统一
- **WHEN** Agent 读取有效历史生成任务
- **THEN** 返回该任务的提示词、参数、来源与素材文件信息
- **AND** 不创建任务或暴露 API Key、账号令牌和敏感下载链接

#### Scenario: 读取生成服务返回缓存
- **WHEN** Agent 请求已有任务的缓存响应
- **THEN** 返回可用的安全响应信息或明确的未缓存状态
- **AND** 不为补齐本地读取结果重新提交生成请求

#### Scenario: 路径越界或文件消失
- **WHEN** 请求通过路径穿越、符号链接或过期文件标识访问授权范围外的文件，或文件已清理
- **THEN** CLI 拒绝或报告文件不可用，不读取无关文件

### Requirement: 本地素材可用于继续创建草稿
CLI SHALL 支持将已读取的项目过程图或生成缓存图用于图片参考图或视频首／尾帧；输入图片 MUST 经现有合法性校验，并保留素材来源信息。生成缓存图片有已保存编辑结果时 SHALL 使用当前已保存版本；未保存编辑不冒充有效素材。素材复用 MUST 只更新指定草稿字段，不提交生成。

#### Scenario: 用步骤输出帧制作新动作
- **WHEN** Agent 选择一个有效过程帧作为新视频首帧
- **THEN** 视频草稿显示该帧及其预览
- **AND** 原提示词、尾帧及其他参数保留

#### Scenario: 复用已编辑候选图片
- **WHEN** Agent 从图片生成缓存选择已保存编辑的候选图作参考
- **THEN** 使用该候选当前保存版本
- **AND** 返回对应任务与候选标识用于溯源
