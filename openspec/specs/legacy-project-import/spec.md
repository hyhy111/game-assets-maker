# legacy-project-import Specification

## Purpose
为从旧版 Video to Sheet 迁移到 Game Assets Maker 的用户提供低干扰、可发现且安全的项目导入能力，使用户可以选择旧版应用目录或其中的 `project` 目录，同时确保源数据保持不变且现有项目不会被覆盖。

## Requirements

### Requirement: 自动识别旧版项目根目录

系统 MUST 接受用户选择的目录，并在有限范围内解析实际的旧版项目根目录。

#### Scenario: 直接选择 project 目录
- **WHEN** 用户选择的目录包含至少一个通过旧版项目校验的直接子目录
- **THEN** 系统 MUST 将所选目录作为实际项目根目录

#### Scenario: 选择旧版应用目录
- **WHEN** 用户选择的目录本身不包含有效旧项目，并且其直接子目录 `project/` 包含至少一个有效旧项目
- **THEN** 系统 MUST 将该 `project/` 子目录作为实际项目根目录

#### Scenario: 不递归搜索其他目录
- **WHEN** 所选目录及其直接子目录 `project/` 均不包含有效旧项目
- **THEN** 系统 MUST 报告未检测到有效旧版项目
- **THEN** 系统 MUST NOT 递归扫描所选目录的其他后代目录或文件系统中的其他位置

### Requirement: 严格校验旧版项目

系统 MUST 仅将包含可读取、可解析的 `cache/global_params.json`，且其中 `project_name` 为非空字符串的目录识别为可导入旧项目。

#### Scenario: 元数据有效
- **WHEN** 候选项目的元数据文件可读取并包含非空 `project_name`
- **THEN** 系统 MUST 将该目录纳入可导入项目列表

#### Scenario: 元数据无效
- **WHEN** 候选目录缺少元数据文件、文件不可读取、JSON 无法解析或 `project_name` 为空
- **THEN** 系统 MUST 排除该目录且不得复制其内容

### Requirement: 复制导入并保护现有数据

系统 MUST 将有效旧项目复制到当前项目根目录，同时保留源目录并保护已有目标项目。

#### Scenario: 成功导入新项目
- **WHEN** 有效旧项目不存在同名目标目录
- **THEN** 系统 MUST 通过临时暂存目录完成复制和复制后校验，再将其作为新项目加入当前项目库
- **THEN** 系统 MUST 保留源项目的全部原始内容

#### Scenario: 同名项目已经存在
- **WHEN** 当前项目根目录中存在与旧项目名称大小写无关匹配的目录
- **THEN** 系统 MUST 跳过该旧项目且不得覆盖或修改现有目标目录

#### Scenario: 实际来源是当前项目目录
- **WHEN** 自动解析后的实际项目根目录等于当前项目根目录
- **THEN** 系统 MUST 拒绝执行导入

#### Scenario: 单个项目复制失败
- **WHEN** 某个旧项目在复制、复制后校验或落盘过程中失败
- **THEN** 系统 MUST 清理该项目的临时暂存内容
- **THEN** 系统 MUST 记录该项目的失败原因，并继续处理其他候选项目

### Requirement: 低干扰的按需导入入口

主页 MUST NOT 常驻显示完整的旧版项目导入卡片，并且 MUST 在用户需要时提供可发现的导入入口。

#### Scenario: 项目库中打开更多菜单
- **WHEN** 动画库区域可见
- **THEN** 系统 MUST 在动画库标题的刷新操作旁提供“更多”菜单
- **THEN** 菜单 MUST 包含“导入旧版项目”操作

#### Scenario: 空项目库显示轻量入口
- **WHEN** 项目库加载完成且没有任何项目
- **THEN** 系统 MUST 在主要创作操作下提供轻量的“从旧版项目导入”文字入口

#### Scenario: 两个入口触发同一流程
- **WHEN** 用户从更多菜单或空项目入口启动导入
- **THEN** 系统 MUST 打开目录选择并执行相同的目录识别、校验和复制流程

#### Scenario: 用户取消目录选择
- **WHEN** 用户关闭目录选择器且没有选择目录
- **THEN** 系统 MUST 保持项目库不变且不显示失败结果

### Requirement: 清晰且非驻留的导入反馈

系统 MUST 在一次导入尝试完成后反馈实际识别的项目根目录以及导入、跳过和失败数量，但主页空闲状态下不得保留导入提示区域。

#### Scenario: 导入完成
- **WHEN** 系统完成对所有候选项目的处理
- **THEN** 系统 MUST 显示实际识别的项目根目录
- **THEN** 系统 MUST 显示已导入、已跳过和失败的项目数量
- **THEN** 系统 MUST 重新加载项目库以展示成功导入的项目

#### Scenario: 未检测到有效项目
- **WHEN** 目录解析未找到有效旧版项目
- **THEN** 系统 MUST 显示可理解的失败提示
- **THEN** 系统 MUST 保持当前项目库和所选源目录不变
